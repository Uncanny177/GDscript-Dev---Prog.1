# Error Screenshots

Drop screenshots of Godot errors here from your home machine.
Then push to GitHub so they're available on the work machine for debugging.

## Workflow:
1. See error in Godot → take screenshot (Win+Shift+S or PrtScn)
2. Save it here (e.g., `error_2024_07_28_combat_crash.png`)
3. Run: `git add -A && git commit -m "error: description" && git push`
4. At work: `git pull` → I can see the screenshots and help fix

## Naming convention:
`error_YYYY_MM_DD_short_description.png`

Examples:
- error_2025_07_28_dungeon_null_ref.png
- error_2025_07_28_combat_skill_crash.png
- error_2025_07_28_title_screen_blank.png
